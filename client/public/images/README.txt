Tips:
  - Square or 4:3 photos look best. Around 800x600 to 1200x900 px.
  - Keep each file under ~300 KB so the site stays fast on mobile data.
  - .jpg or .png both work. If you use .png, update the file name in
    server/src/data/products.js and run "npm run seed" again.

Any item without a photo shows a coloured card with an emoji instead,
so the site never looks broken while you collect the pictures.
